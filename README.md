# Merin Player

Support page, privacy policy and a test playlist for Merin Player, an IPTV player for smart TVs.

- Site: https://tugayakin.github.io/merin-player/
- Test playlist: https://tugayakin.github.io/merin-player/test/playlist.m3u

The test playlist uses only official test streams (Mux, Apple) and Creative Commons films from the Blender Foundation (Big Buck Bunny, Tears of Steel — CC BY 3.0). The TV guide is rebuilt daily by GitHub Actions.
